## 프로젝트명
지능형 기동지원 군사상황 정보판단 프로그램

## 배포 주소 (URL)
https://military-mobility-ai.vercel.app

## 한 줄 소개
공개 도로 CCTV와 ISR·UAV 영상을 AI로 융합해 기동로 구간별 기동 가능성(Go/Slow-Go/No-Go)과 우회로를 판단

## 어떤 문제를 해결하나요?
부대가 차량으로 이동할 때 지휘관은 경로의 교통 상황과 위협 여부를 여러 출처에서 따로 확인해야 하고, 판단과 보고에 시간이 걸립니다. 이 프로그램은 출발점·도착점만 정하면 경로 위의 공개 도로 CCTV와 ISR·UAV 영상을 AI로 자동 분석해, 구간별 기동 가능성과 우회로, 상황 보고서를 한 화면에서 만들어 줍니다. 새 장비 없이 이미 깔린 공공 교통 인프라를 활용하는 저비용 상황인식 방식입니다.

## 주요 기능
1. 기동로 분석: 출발·도착점 → 도로망 경로 탐색 → 경로 위 국가교통정보센터 CCTV 자동 선택·실시간 영상 분석
2. 교통 판단: YOLO11 차량 탐지 + ByteTrack 추적으로 원활·서행·정체·돌발상황(장시간 정차) 판단, CCTV 화면 글자·추적 오류 등 실제 오탐 보정
3. ISR·UAV 위협 탐지: 학습 없이 글로 대상을 지정하는 YOLOE로 기갑·화력 차량, 군용 차량, 도로 장애물, 연기·화재 징후 탐지 (분할 탐지·동영상 반복 확인)
4. 기동 가능성 판단: 교통과 위협을 합쳐 구간별 Go / Slow-Go / No-Go, 기동 불가 시 위협 지점을 2km 이상 피하는 우회로 자동 제시
5. 지점 주변 융합 분석: 기준 지점 반경의 CCTV와 ISR을 방위·거리로 함께 분석
6. 상황 보고서 자동 작성(위협·구간별 판단·조치 건의), 분석 기록 저장(Supabase)
7. 시연 모드(기본, API 호출 없음)와 실시간 모드: 사이드바의 "시연 모드" 스위치를 끄고 비밀번호 12345 입력 시 실시간 CCTV로 분석

## 현장 활용 시나리오
- 부대 이동·수송 전: 계획 경로의 실시간 교통과 위협 후보를 확인하고 우회로를 미리 판단
- 재난 대민지원: 폭설·호우·사고 시 투입 경로의 정체·돌발상황을 확인해 투입 순서 결정
- 당직·상황실: 정찰 UAV 사진·영상을 올려 기준 지점 주변 위협을 방위·거리로 정리하고 상황 보고서를 바로 작성

## 제작 후기 · 어려웠던 점
처음에는 위치 기반 CCTV 교통 분석으로 시작했지만, 내비게이션과 차별화하려고 ISR·UAV 위협 분석을 더해 군사 기동 판단 도구로 확장했습니다. 실제 CCTV에서는 화면에 찍힌 지점명·숫자를 차량으로 인식하거나, 정체 줄의 차량을 사고로 판단하는 오탐이 많아 실제 영상을 보며 판단 기준을 하나씩 보정했습니다. 학습 없이 쓰는 위협 탐지는 전차·장갑차 같은 세부 구분이 어려워 '기갑·화력 차량'으로 묶어 판단하고, 최종 판단은 사람이 하도록 했습니다(타격 지정 기능 없음, 얼굴·번호판 등 개인 식별 없음). API 월 호출 한도와 무료 서버 제약 때문에 분석 서버는 개인 노트북에서 동작하며, 서버가 꺼져 있을 때는 미리 녹화한 분석 시연(https://military-mobility-ai.vercel.app/?replay)과 지난 분석 기록을 볼 수 있습니다.
